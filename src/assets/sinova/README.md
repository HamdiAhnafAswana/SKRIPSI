# SINOVA Assets

Folder untuk aset visual SINOVA (Simulation Interactive Network Virtual Academy).

## Style Guide

- 3D educational game
- Semi realistic cartoon
- Dark blue cyber laboratory theme
- Modern networking simulation
- Clean UI asset
- High Quality

## Aset yang Dibutuhkan

1. **Karakter Andi** - 3D cartoon network technician dengan helm biru dan seragam
2. **Sarung Tangan** - Alat pelindung tangan untuk jaringan
3. **Cable Stripper** - Pengupas kabel jaringan
4. **Crimping Tool** - Tang crimping RJ45
5. **LAN Tester** - Alat tes kabel jaringan
6. **RJ45 Connector** - Konektor RJ45
7. **Network Switch** - Switch 8 port
8. **Computer PC** - Workstation untuk lab jaringan
9. **Network Lab Background** - Background laboratorium jaringan

## Catatan

Aset visual saat ini menggunakan Canvas drawing. Aset gambar akan ditambahkan di folder ini.
